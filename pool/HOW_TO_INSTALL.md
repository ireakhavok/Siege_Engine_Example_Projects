# Install

Copy this `pool` folder next to `bowling` in the example projects repo.

`Scripts/Libs` already has the same `SiegeEngine.dll` and `Foundation.dll` bowling builds against. The csproj HintPath assumes the folder is `C:\repos\Siege_Engine_Example_Projects\pool`. If yours is elsewhere, change the two HintPath lines.

Open the folder as a project in Castle and press Play. The scene class is `PoolScene`.
